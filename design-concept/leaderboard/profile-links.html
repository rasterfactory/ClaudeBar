Profile links

Members can add one profile link (X, Instagram or GitHub) so people on the board can find them. Only a handle is stored; the link is always built from the platform's own address. Handles are not verified, and the board says so.

    Profile links are added by each member and aren't verified.

    Handles, not URLs

    Members type a handle; the link is built as x.com/, instagram.com/ or github.com/ + handle. Each platform's username rules are checked, so a link can never point anywhere else.

    Not verified, and said so

    Anyone could type anyone's handle. The icon's tooltip and the web board say links are added by members and not checked. Links open with rel="nofollow ugc noopener".

    Removable, moderated

    Remove it in Settings any time; leaving deletes it. A suspended member's link is hidden, and the admin can clear any link.
