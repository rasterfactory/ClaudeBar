4 · What your terminal does

The rules

New sessions only

Switching writes one file. A session that is already running keeps its login, and is never interrupted.

No secrets move

The file holds a folder path. Each login keeps its own Keychain item and refresh token, so nothing gets logged out.

Asked once, easy to undo

The shell lines are shown before they're written. Deleting them, or choosing the plain login, gives you the CLI's own behaviour back.

Terminal only

Claude Desktop and IDE extensions don't run your shell, so they keep their own login. The popover says so.

Switch when low is opt-in

Off by default. It only picks among logins you tick, and tells you every time it switches.
